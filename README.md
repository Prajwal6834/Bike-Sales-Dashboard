# Bike Sales Dashboard Using Python

## Project Description
This project is a Bike Sales Dashboard developed using Python. It visualizes bike sales data through different types of graphs.

## Technologies Used
- Python
- Tkinter
- Pandas
- Matplotlib
- CSV Dataset

## Features
1. Line Graph
2. Bar Graph
3. Histogram
4. Scatter Graph
5. X-Axis and Y-Axis column selection
6. Interactive graphical interface

## Installation

Install the required libraries:

```bash
pip install pandas matplotlib
```

## How to Run

1. Download or clone this repository.
2. Keep `bike_sales_india.csv` in the same folder as the Python file.
3. Open the project in VS Code.
4. Run:

```bash
python bike_sales_dashboard.py
```

## Project Files
- `bike_sales_dashboard.py` – Main Python program.
- `bike_sales_india.csv` – Bike sales dataset.
